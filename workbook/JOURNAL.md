# Project Journal

One entry per module, plus extra entries whenever something worth remembering happens. Bullet points are enough. Nobody grades this; it exists so the retrospective in Module 19 writes itself, and so a session two weeks from now starts from notes and not from memory.

```
-
```

Each module's section 12 has a prompt with a few module-specific things to note in addition to the template.
